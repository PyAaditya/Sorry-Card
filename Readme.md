## ✨ What is this?

A single-file, interactive digital apology card — pastel pink & lavender palette, hand-illustrated SVG characters, and a runaway **"Nahi"** button that turns forgiveness into a whole cute little game.

## 🚀 Quick Start

```bash
git clone https://github.com/PyAaditya/Sorry-Card.git
cd Sorry-Card
```

Open `index.html` in any browser. That's it — no build step, no server, no dependencies.

> Prefer not to use git? Click **Code → Download ZIP**, extract, and open `index.html`.

<br>

## 🌍 Deploy Your Own — Free, in 2 Minutes

```
1. Fork this repo (or push your customized index.html to a new repo)
2. Settings → Pages
3. Branch: main   Folder: /root
4. Save
```

Your card goes live at `https://<your-username>.github.io/<repo-name>/`

> ⚠️ File must be named exactly `index.html` to load automatically.
